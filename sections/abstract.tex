\begin{abstract}
Storage scalability is paramount in the era of big data blockchain.
Prior research has extensively utilized sharding techniques to attain storage scalability; however, these often compromise safety and liveness guarantees.
In this work, we present \sys, a novel Byzantine Fault Tolerant (BFT) protocol where the aggregate storage consumption is independent of the node count and can tolerate $f$ Byzantine faults among $3f+1$ nodes within a partially synchronous network.
The core design of \sys involves a state management system decoupled from the execution layer.
This state management system employs sharding to ensure state availability with scalable storage consumption, while the global consensus and execution layers maintain robust security characteristics.
We analyze the redundancy and network traffic overhead associated with \sys.
Preliminary findings indicate that \sys achieves superior storage scalability compared to existing approaches while incurring acceptable network overhead.
\end{abstract}
