\section{Conclusion}

In this work we present \sys, a BFT protocol with scalable storage consumption.
\sys's state management is inspired by distributed databases, and it also inherits the consistent ordering and execution from blockchain protocols.
We believe \sys opens up a wide range adoption opportunities of both blockchains and databases.
Based on \sys, several future directions such as developing collaborative databases across mutually untrusted organizations and designing execution model for on-chain big data processing can be explored.
In the future, more data can be collaboratively managed in more possible ways.
